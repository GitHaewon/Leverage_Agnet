# AI Trading Copilot

> AI가 24시간 암호화폐 시장을 지켜보고, 대신 거래해주는 서비스입니다.

---

## 이게 뭔가요?

한 문장으로 요약하면:

> **비트코인·이더리움 선물 거래를 AI가 자동으로 대신 해주는 구독 서비스**입니다.

직접 차트를 볼 필요 없습니다. 잠을 자는 동안에도 AI가 시장을 보고, 지금 사야 할지 팔아야 할지 판단하고, 주문을 냅니다. 거래가 끝나면 결과 리포트도 자동으로 만들어 줍니다.

---

## 어떤 분들을 위한 서비스인가요?

| 이런 분들께 | 이유 |
|---|---|
| 암호화폐 투자에 관심 있지만 차트 볼 시간이 없는 직장인 | AI가 24시간 대신 모니터링 |
| 감정적으로 판단해서 손해를 자주 보는 분 | AI는 규칙대로만 거래, 감정 없음 |
| 자동매매를 써보고 싶은데 어디서 시작할지 모르는 분 | API Key만 등록하면 바로 시작 |
| 리스크 관리가 걱정되는 분 | 손절가 없으면 아예 주문을 안 냄 |

**수익을 보장하는 서비스가 아닙니다.** 암호화폐 선물 거래는 원금 손실이 가능한 고위험 투자입니다. AI가 더 일관된 규칙으로 거래할 수 있을 뿐입니다.

---

## 어떻게 작동하나요?

AI가 순서대로 5가지 분석을 합니다. 5가지를 모두 통과해야만 실제 주문이 나갑니다.

```
1단계  차트 분석
       RSI, MACD, 볼린저 밴드 등 기술적 지표를 계산합니다.
       쉽게 말해 "최근 가격 흐름이 어떤가?" 를 봅니다.
           ↓
2단계  뉴스·심리 분석
       최신 뉴스를 AI가 읽고 긍정/부정을 점수로 매깁니다.
       공포/탐욕 지수도 확인합니다. (극단적 공포 = 매수 기회일 수 있음)
           ↓
3단계  파생상품 시장 분석
       "지금 시장에서 큰손들이 어느 방향에 베팅하고 있는가?" 를 봅니다.
       미결제약정, 펀딩비, 롱/숏 비율을 확인합니다.
           ↓
4단계  AI 최종 판단  (Claude AI)
       위 3가지 데이터를 모두 받아서 LONG / SHORT / HOLD 중 하나를 결정합니다.
       신뢰도가 60% 미만이면 "지금은 거래하지 않는다"고 판단합니다.
           ↓
5단계  리스크 검증  (안전 게이트)
       손절가가 있는가? 목표:손실 비율이 2:1 이상인가?
       레버리지가 한도 이내인가? 일일 손실 한도를 넘지 않는가?
       하나라도 실패하면 주문은 취소됩니다.
```

## 어떻게 안전하게 관리하나요?

### 자금 보호

이 서비스는 **거래 권한만 있는 API Key**만 허용합니다.
출금 권한이 있는 Key를 등록하려 하면 시스템이 즉시 거부합니다.
최악의 경우에도 거래소 계정에서 돈이 외부로 빠져나가는 것은 막혀 있습니다.

### 자동 중단 규칙

아래 상황이 되면 자동매매가 자동으로 멈춥니다.

| 상황 | 중단 기간 |
|---|---|
| 오늘 손실이 설정한 일일 한도에 도달 | 오늘 자정까지 |
| 이번 주 손실이 주간 한도에 도달 | 다음 월요일까지 |
| 같은 방향으로 5번 연속 손실 | 수동으로 재시작할 때까지 |
| 계좌 잔고가 고점 대비 20% 하락 | 수동으로 재시작할 때까지 |
| Binance API 연결이 3번 연속 끊김 | 30분 |
| 긴급 중단 (본인이 직접 발동) | 수동으로 재시작할 때까지 |

### 주문이 나가기 전에 반드시 확인하는 것들

- 손절가(Stop Loss)가 설정되어 있는가? → 없으면 주문 불가
- 목표가:손절가 비율이 2:1 이상인가? → 미달이면 주문 불가
- AI 신뢰도가 60% 이상인가? → 미달이면 HOLD
- 레버리지가 한도 이내인가? → 초과 시 자동으로 낮춤
- 일일/주간 손실 한도가 남아 있는가? → 초과 시 주문 불가

## AI가 주문을 낼 때 보내는 신호 예시

AI가 분석을 마치면 이런 형태로 시그널을 만듭니다.

```
코인:      BTC (비트코인)
방향:      LONG (가격이 오를 것으로 예상)
신뢰도:    78%
진입가:    $67,500
목표가:    $69,800  (목표 수익)
손절가:    $66,350  (손실 한도)
레버리지:  5배
근거:
  RSI(14)=38로 과매도 구간. MACD 골든크로스 형성 중.
  볼린저 밴드 하단 반등 확인, 미결제약정 증가 + 펀딩비 음수로 롱 유리.
  공포/탐욕 지수 29(극단적 공포)로 단기 반전 가능성 높음.
```

이 시그널이 위에서 설명한 리스크 검증을 통과해야 실제 주문으로 이어집니다.

## 직접 실행해보기 (개발자용)

> 데이터베이스 없이도 프론트엔드 화면을 바로 체험할 수 있습니다.

**필요한 것:** Node.js (https://nodejs.org 에서 무료 설치)

**1단계 — 소스 코드 받기**

```bash
git clone <repo-url>
cd Leverage_Agent/frontend
npm install
```

**2단계 — 가짜 API 서버 시작** (새 터미널 창에서)

```bash
node mock-server.mjs
```

이 서버가 실제 데이터베이스 없이 모든 API 응답을 흉내냅니다.

**3단계 — 웹 화면 시작**

```bash
npm run dev
```

**4단계 — 브라우저 접속**

```
주소:     http://localhost:3000
이메일:   demo@trading.com
비밀번호: Demo1234!
```

## 전체 시스템 실행하기 (Docker 사용)

> PostgreSQL, Redis, AI 서버, 웹 화면을 한 번에 실행합니다.
> Docker Desktop (https://www.docker.com) 설치가 필요합니다.

**1단계 — 설정 파일 준비**

```bash
cp .env.example .env
```

`.env` 파일을 열어서 아래 4개 값은 반드시 채워야 합니다.

| 항목 | 발급 방법 |
|---|---|
| `ANTHROPIC_API_KEY` | https://console.anthropic.com → API Keys |
| `BINANCE_ENCRYPT_KEY` | 터미널에서 `python3 -c "import secrets; print(secrets.token_hex(16))"` 실행 |
| `JWT_SECRET` | 터미널에서 `python3 -c "import secrets; print(secrets.token_hex(32))"` 실행 |
| `JWT_REFRESH_SECRET` | 위와 동일한 방법으로 다른 값 생성 |

**2단계 — 실행**

```bash
docker compose up -d
```

처음 실행 시 2~3분이 소요됩니다.

**3단계 — 접속 주소**

| 서비스 | 주소 | 설명 |
|---|---|---|
| 웹 대시보드 | http://localhost:3000 | 메인 화면 |
| API 문서 | http://localhost:8000/docs | 개발자용 |
| 모니터링 | http://localhost:3001 | Grafana (admin/admin) |

**종료**

```bash
docker compose down
```

## 환경변수 안내

`.env.example` 파일을 복사해서 `.env`를 만들고 사용합니다.

> `.env` 파일에는 비밀번호와 API 키가 들어 있습니다. 절대 GitHub에 올리지 마세요.

### 주요 항목 설명

**Binance 설정**

| 항목 | 설명 |
|---|---|
| `BINANCE_TESTNET=true` | 개발 중에는 반드시 `true`. 가상 자금으로만 거래됩니다. |
| `BINANCE_ENCRYPT_KEY` | API Key를 암호화해서 저장할 때 쓰는 32자리 비밀 키 |

Binance Testnet API Key 발급: https://testnet.binancefuture.com → 계정 → API Key
(읽기 + 거래 권한만 선택. **출금 권한은 절대 체크하지 마세요.**)

**텔레그램 설정**

텔레그램 앱에서 `@BotFather`를 검색 → `/newbot` 입력 → 토큰 복사 → `TELEGRAM_BOT_TOKEN`에 붙여넣기

**이메일 설정 (Gmail 기준)**

Google 계정 → 보안 → 2단계 인증 활성화 → 앱 비밀번호 생성 (16자리) → `SMTP_PASSWORD`에 입력

**Stripe 결제 설정**

https://dashboard.stripe.com → Developers → API Keys → Secret Key 복사 → `STRIPE_SECRET_KEY`에 입력

## 자주 묻는 질문

**실제 돈으로 거래가 되나요?**

기본 설정(`BINANCE_TESTNET=true`)에서는 가상 자금으로만 거래됩니다. 실제 거래를 원한다면 `BINANCE_TESTNET=false`로 바꾸고 실제 Binance Futures API Key를 등록해야 합니다.

---

**수익을 보장하나요?**

아닙니다. AI는 확률적으로 유리한 시점을 찾는 것이지 수익을 보장하지 않습니다. 암호화폐 선물 거래는 원금 전액 손실이 가능한 고위험 투자입니다.

---

**어떤 코인을 거래하나요?**

현재는 BTC(비트코인)와 ETH(이더리움) 선물만 지원합니다.

---

**자동매매를 언제든 멈출 수 있나요?**

네. 대시보드에서 즉시 중단할 수 있습니다. 또한 손실이 설정한 한도에 도달하거나, 청산 위험이 감지되거나, 거래소 API가 끊기면 시스템이 자동으로 멈춥니다.

---

**API Key가 유출되면 어떻게 되나요?**

이 서비스는 출금 권한이 없는 Key만 등록을 허용합니다. 유출되더라도 거래소 자금이 외부로 출금되는 것은 불가능합니다. Key는 암호화된 형태로 저장되며, 주문 실행 직전에만 잠깐 복호화됩니다.

---

**지금 실제로 사용할 수 있나요?**

현재 개발 완성도 약 95%의 베타 단계입니다. 핵심 기능은 모두 구현되어 있으며, 최종 QA 및 외부 테스트 중입니다.
